# spdlog 中文文档翻译风格指南

## 核心原则

1. **准确性优先** —— 术语翻译必须准确，遵循术语表（config/glossary.yml 为唯一来源）
2. **专业性** —— 使用专业技术文档语言，避免口语化
3. **一致性** —— 同一术语全文统一译名
4. **可读性** —— 符合中文技术文档阅读习惯

## 翻译规则

### 1. 代码与标识符保持原文

| 类型 | 处理方式 | 示例 |
|------|----------|------|
| 代码块（```cpp ... ```） | 完全保持原文 | `spdlog::info("{}", 42);` |
| 内联代码 | 完全保持原文 | 使用 `spdlog::set_level` 函数 |
| 函数名/类名/宏名 | 保持英文原名 | `spdlog::logger`、`SPDLOG_TRACE` |
| 头文件名 | 保持英文原名 | `<spdlog/spdlog.h>`、`<spdlog/async.h>` |
| 变量名/参数名 | 保持英文原名 | `filename_pattern`、`max_files` |
| 模式标志（pattern flags） | 保持英文原名 | `%v`、`%l`、`%Y-%m-%d` |
| 版本号/数字/构建选项 | 保持原格式 | v1.17.0、`SPDLOG_BUILD_EXAMPLE` |

### 2. 专业术语使用术语表

- 首次出现括注原文：`接收器（sink）`
- 后续统一使用中文译名
- 术语表未收录的术语，首次使用时在批次报告中提议并加入术语表（PR 流程）
- 禁用译名黑名单（glossary.yml `banned:`）由校验器机器扫描，0 违规为硬门禁

### 3. 人称与语气

| 场景 | 推荐 | 避免 |
|------|------|------|
| 您/用户 | 您可以使用... | 你可以用... |
| 我们/作者 | 我们建议... | 我建议... |
| 一般陈述 | 此库提供... | 这个库挺好用的... |
| 指令 | 请参阅... | 你看一下... |

### 4. 标点与排版

| 规则 | 示例 |
|------|------|
| 中文句子用中文标点 | 请参阅 `spdlog::info` 文档。 |
| 中英文/数字之间加空格 | 使用 `spdlog` 库、约 2 倍性能 |
| 夹杂代码时合理混用 | 函数 `spdlog::error` 输出到 stderr。 |
| 代码块内保持原文标点 | 代码块内不翻译任何内容 |
| 全角标点仅在中文句内使用 | 代码、URL、文件名内保持半角 |

### 5. 数字与单位

| 规则 | 示例 |
|------|------|
| 阿拉伯数字 | 版本 1.17.0 |
| 数字与单位间加空格 | 约 20-30 倍 |
| 版本号/编译器版本保持原格式 | GCC 4.8+、C++11 |

### 6. Markdown 格式规范

| 元素 | 处理方式 |
|------|----------|
| 标题层级 | 保持原文层级（# ## ###） |
| 列表符号 | 保持原文符号（- * 1.） |
| 表格 | 保持原文结构，仅翻译单元格文本 |
| 链接显示文本 | 可译；链接目标（URL 与 .md 文件名）不译 |
| 图片 alt 文本 | 可译 |
| 提示块（***Note*** 等） | Note/Tip/Warning 译为 注/提示/警告，标记样式保留 |
| 代码块内注释 | 保持原文——代码块逐字不动；确需解释时在代码块后以正文补注 |
| [[wiki-link]] | 上游已不存在此语法（sync 期已规范化为标准链接），译文中不得新引入 |

### 7. 常见术语对照（与 glossary.yml 一致，此处为速查）

| 英文 | 中文 | 备注 |
|------|------|------|
| logger | 日志记录器 | |
| sink | 接收器 | 首现括注（sink） |
| formatter | 格式化器 | |
| pattern formatter | 模式格式化器 | |
| flush | 刷新 | |
| log level | 日志级别 | 级别名 trace/info/... 保持英文 |
| async logger / async mode | 异步日志记录器 / 异步模式 | |
| overflow policy | 溢出策略 | |
| ring buffer | 环形缓冲区 | |
| thread pool | 线程池 | |
| backtrace | 回溯 | |
| rotation | 轮转 | |
| header-only | 仅头文件 | |
| error handler | 错误处理器 | |
| format string | 格式字符串 | |

## 审校检查清单

- [ ] 所有术语表术语是否统一使用，黑名单 0 命中
- [ ] 代码块/内联代码/HTML/URL/链接目标是否保持原文
- [ ] 标题层级/列表/表格结构是否完整
- [ ] 中英文间空格、全角标点是否规范
- [ ] 人称是否统一为"您"/"我们"
- [ ] 语气是否专业、简洁
- [ ] 无遗漏翻译段落、无 PROTECTED_* 占位符残留

## 争议处理

1. 术语翻译有歧义时，在 PR 讨论区决议后更新 glossary.yml
2. 更新术语表后，需同步检查所有已翻译文件（validate 全量跑术语扫描）
3. 重大分歧由维护者裁决并记入 decision_log（仅重大时）
