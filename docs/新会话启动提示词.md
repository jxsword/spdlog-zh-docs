## 硬性纪律（同 M2/M3，重申）

1. 所有脚本/构建一律 memgate 包裹；mkdocs 用 `.venv/bin/mkdocs`；构建产物出仓库树；文件写入用 Write/Edit 工具（hook 拦 Bash 直写）
2. 门禁硬性化：全部退出码生效（勿被管道 tail / diff 退出码截断 && 链），禁止 `|| true`；黑名单 0 命中、占位符还原 100%
3. 代码块/内联代码/API 名/链接目标不译（含代码注释）；"不增不减"优先于术语告警；中英文间空格、全角标点
4. 每次 sync/批次一个 squash commit；决策变更先更新 decision_log 再执行；半成品不入库
5. 子代理声明一律不可信——门禁以编排方亲跑为准
6. 模拟上游/演练类 PR 必须**关闭不合并**（state.upstream_commit 污染真基线会破坏下次 sync）
7. 上下文过半或里程碑收尾主动建议开新会话并更新本启动提示词
